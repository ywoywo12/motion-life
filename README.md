# Motion Life — النظام المبسط

نظام عربي بسيط لملف المريض والتقييم السريري والخطة العلاجية (22 جلسة)، مع مكتبة تمارين مصوّرة وبروتوكولات الأجهزة.

- يعمل من المتصفح مباشرة (GitHub Pages) بدون خادم.
- البيانات تُحفظ على جهاز ومتصفح المستخدم؛ استخدم «الإعدادات ← تنزيل نسخة احتياطية» بانتظام.
- الدخول الافتراضي: `admin` / `Motion2026` — غيّره من الإعدادات بعد أول دخول.
