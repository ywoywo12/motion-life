# Motion Life — النظام المبسط

نظام عربي لملف المريض والتقييم والخطة العلاجية والمواعيد، مع مكتبة تمارين مصوّرة وبروتوكولات الأجهزة.

- قسم النساء: مواعيد 9:00 ص – 3:00 م · قسم الرجال: 3:00 م – 9:00 م · موعد كل 10 دقائق.
- ثلاثة حسابات: `women` (النساء فقط)، `men` (الرجال فقط)، `admin` (الإدارة، القسمان كلٌّ بجدول منفصل).
- المزامنة اللحظية بين الأجهزة عبر Firebase (يُضبط مرة واحدة من صفحة «إعداد المزامنة» ثم يوضع الإعداد في `firebase-config.js`).
- التسجيل الصوتي وتحويله لكتابة في: القصة المرضية، الأعراض الحالية، القيود والصعوبات، الخطة العلاجية (Chrome / Edge / Safari).
