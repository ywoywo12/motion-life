# معايير القبول والاختبارات الآلية

التشغيل:
```bash
python3 -m unittest -v tests.test_rules tests.test_security tests.test_acceptance
```
- `tests.test_rules` لا يحتاج قاعدة بيانات.
- البقية تعيد إنشاء قاعدة الاختبار `motionlife_test` من الصفر، فلا تمس بيانات التطوير.

**نتيجة آخر تشغيل في بيئة البناء:** 39 اختباراً، **كلها ناجحة**. التفاصيل في README.

## اختبارات إضافية (`test_security`)

- قفل الدخول بعد 5 محاولات، ورسالة موحدة (لا كشف لوجود المستخدم).
- CSRF وفحص Origin.
- XSS: الاسم والملاحظات تُعرض مُهرّبة، مع CSP صارم.
- كشف التكرار بالاسم المطبّع، وكذلك بالهاتف بصيغة دولية.
- لا تعديل ذاتي للدور. مسؤول النظام لا يعدّل المدير. التعطيل يُنهي الجلسات فوراً.
- المعرّفات غير الصالحة تعيد 404.
- عرض الصفحات لكل دور، مع رموز الحالة المتوقعة لكل صفحة.

## اختبارات يدوية وبصرية منفذة

- لقطات شاشة بعرض هاتف 390px وكمبيوتر 1366px عبر Chromium (`scripts/screenshots.py`): لا أخطاء JavaScript ولا انتهاكات CSP في وحدة التحكم.
- تحويل صفحات PDF لصور وفحصها بصرياً: الاتجاه والأرقام وجدول الجلسات الـ22.
- دورة نسخ احتياطي ثم استعادة حقيقية (`backup.sh` ← `restore.sh`) ومطابقة أعداد الصفوف.

## لم يُختبر (بصدق)

- مشغّل `psycopg` (غير متوفر في البيئة؛ المسار المختبر هو libpq).
- Docker/docker-compose (لا يوجد Docker daemon).
- النشر الفعلي على Hostinger.
- قارئ شاشة حقيقي (تم فقط ترميز ARIA والتسميات والتنقل بلوحة المفاتيح بنيوياً).
- اختبار أداء تحت حمل.
