# ربط حقول الملفات المرجعية ببيانات النظام وصفحاته

المصدران:
- **[H]** = `Motion_Life_Medical_History_Form_AR.pdf` (استبيان التاريخ الطبي، 7 صفحات، 15 قسماً + قسم الفريق + الملخص).
- **[F]** = `Motion_Life_Patient_File_2Pages_AR_v7.pdf` (ملف المريض والتقييم + الخطة ومتابعة حتى 22 جلسة).

الرموز في عمود «التخزين»:
- `patients.*` أعمدة مباشرة في جدول المرضى.
- `answer:CODE` إجابة في محرك الاستبيان (جدول `answers` مرتبط بـ`question_definitions` بإصدار محدد).
- `entries:TYPE` صفوف قائمة متعددة في `medical_history_entries`.

العلامة **➕** تعني حقلاً **إضافياً غير موجود في المصادر** أضفناه لأن البرومبت يطلبه أو لأسباب السلامة.

## 4. أسئلة السلامة [H§4]

المصدر يستعمل **مربعات تأشير** و«لا شيء مما سبق». هذا لا يميّز بين «لا» و«لم يُسأل». لذلك حوّلنا **كل** بند إلى سؤال مستقل بأربع قيم: `نعم / لا / غير معروف / لم يُسأل`. القيمة الافتراضية **لم يُسأل**، ولا يُعتبر الفراغ نفياً أبداً.

| بند المصدر | السؤال في النظام |
|---|---|
| ألم أو ضغط غير معتاد في الصدر | `SF_CHEST_PAIN` |
| ضيق نفس غير معتاد | `SF_DYSPNEA` |
| ألم شديد مستمر وغير معتاد ليلاً | `SF_NIGHT_PAIN` |
| خدر حديث حول المنطقة بين الفخذين/الأعضاء التناسلية | `SF_SADDLE_NUMBNESS` |
| فقدان حديث للسيطرة على البول أو البراز | `SF_BLADDER_BOWEL_CONTROL` |
| ضعف جديد أو سريع التفاقم في طرف | `SF_PROGRESSIVE_WEAKNESS` |
| فقدان مفاجئ للتوازن أو القدرة على الحركة | `SF_SUDDEN_BALANCE_LOSS` |
| سقوط أو إصابة حديثة مهمة | `SF_SIGNIFICANT_TRAUMA` |
| إغماء أو دوار شديد حديث | `SF_SYNCOPE` |
| تورم/ألم حديث وغير معتاد في ساق واحدة | `SF_UNILATERAL_LEG_SWELLING` |
| حمى/ارتفاع حرارة غير مفسر | `SF_FEVER` |
| نقص وزن غير مقصود | `SF_WEIGHT_LOSS` |
| «لا شيء مما سبق» | **أُلغي عمداً**: لا يوجد زر «الكل لا». يُسأل كل بند صراحةً، لأن التأشير الجماعي يخلط «لا» بـ«لم يُسأل» |
| احتباس بول حديث / صعوبة جديدة بالتبول ➕ (من البرومبت §6ب) | `SF_URINARY_RETENTION` |
| أعراض عصبية بالساقين معاً حديثة ➕ | `SF_BILATERAL_LEG_SYMPTOMS` |
| ألم بطني/ظهري شديد مفاجئ نابض ➕ (وعائي حاد) | `SF_ACUTE_VASCULAR` |
| تاريخ سرطان (مأخوذ من §5) | `HX_COND_CANCER` يُستعمل في القواعد |
| عوامل خطر عدوى (كبت مناعة، إجراء/عدوى حديثة) ➕ | `SF_INFECTION_RISK` |

قواعد التقييم موثّقة في `docs/clinical-rules.md`.

## 5. التاريخ الطبي [H§5]

كل مرض في القائمة سؤال مستقل `HX_COND_*` بقيم (نعم/لا/غير معروف/لم يُسأل)، وهذه هي الأمراض:
اضطرابات دموية، هشاشة العظام (`HX_COND_OSTEOPOROSIS`، تُستعمل في قاعدة احتمال الكسر)، ارتفاع الضغط، مشاكل الدورة الدموية، روماتيزم/مرض مناعي، أمراض القلب، جلطة وريدية/صمة رئوية سابقة، صرع/اختلاج، اضطراب نظم القلب، سرطان حالي أو سابق (`HX_COND_CANCER`)، باركنسون، جلطة قلبية سابقة، مرض معدٍ مهم، التصلب المتعدد، جلطة دماغية/نقص تروية، حالة نفسية/معرفية، إصابة دماغية/عصبية، السكري، أمراض الكلى، الغدة الدرقية، الكبد، تنفسية/ربو، حالة أخرى.
«تفاصيل مهمة، سنة التشخيص» ← `answer:HX_COND_DETAILS`.

## 8. الأجهزة المزروعة [H§8]

منظم ضربات القلب، مزيل رجفان مزروع، محفز عصبي مزروع، مضخة دوائية/إنسولين، قوقعة مزروعة، مفصل صناعي، صفائح/براغي، زرعات بالعمود الفقري، أخرى، لا يوجد. التخزين: `answer:HX_IMPLANTS` (متعدد مع خيار «لا يوجد» حصري)، والتفاصيل في `HX_IMPLANT_DETAILS`. **تُعرض كتحذير** على أي بند جهاز في الخطة: «راجع تعليمات الشركة المصنعة لهذا الجهاز بخصوص: …». لا يحكم النظام آلياً بأن الجهاز ممنوع.

## 9. الفحوص والصور [H§9]

صورة شعاعية، رنين، طبقي محوري، أمواج فوق صوتية، تخطيط أعصاب، تحاليل، أخرى، لم أجرِ فحوصاً ← `answer:HX_INVESTIGATIONS`. تاريخ آخر فحص ← `HX_INVEST_DATE`. التقارير أحضرتها/غير متوفرة ← `HX_INVEST_AVAILABLE`. أهم نتيجة ← `HX_INVEST_FINDING`.
➕ في فحص أسفل الظهر نفصل بين **ما يقوله التقرير** (`LB_IMAGING_REPORT_TEXT`) و**الانطباع السريري** (`LB_IMAGING_CLINICAL_RELEVANCE`)، ونعرض تنبيهاً بأن مستوى الجذر العصبي لا يُحدَّد من التقرير وحده.

## 11. نمط الحياة [H§11]

مستوى النشاط ← `HX_ACTIVITY_LEVEL`. طبيعة العمل (مكتبي/وقوف/بدني/قيادة/متقاعد/أخرى) ← `HX_WORK_TYPE`. التدخين ← `HX_SMOKING`. وسيلة مساعدة في المنزل ← `HX_HOME_AIDS`.

## 12. صحة المرأة [H§12]

حمل حالي أو محتمل: لا/نعم/غير متأكدة/لا ينطبق ← `HX_PREGNANCY`. يظهر فقط عندما يكون الجنس أنثى. «نعم» أو «غير متأكدة» يُظهر تحذير احتياطات على بنود الأجهزة في الخطة.

## 13. الأهداف [H§13]

قائمة الأهداف (تخفيف الألم، زيادة القوة، مدى الحركة، المشي، التوازن، اليد، العودة للعمل، العودة للرياضة، التعافي بعد عملية، الوقاية، الاستقلال، أخرى) ← `HX_GOALS`. «أهم هدف…» ← `HX_MAIN_GOAL`.
➕ في الفحص تتحول إلى **أهداف قابلة للقياس** (جدول `goals`: الوصف، المقياس، قيمة البداية، الهدف، الوحدة، التاريخ المستهدف).

## 14. معلومات إضافية [H§14]

← `HX_ADDITIONAL`.

## 15. إقرار المريض [H§15]

**قرار تصميمي:** النظام **لا** يسجّل إقراراً أو توقيعاً نيابة عن المريض. يوجد حقل `HX_DECLARATION_PAPER` (الإقرار موقَّع ورقياً: نعم/لا/غير معروف) مع اسم الموقِّع وصلته. يُسجَّل هذا كـ«تصريح الموظف بوجود إقرار ورقي موقّع»، وليس توقيعاً إلكترونياً. التوقيع الإلكتروني الحقيقي مؤجل لـ V2، ويحتاج إجراء موافقة موثقاً.

## فجوات/ملاحظات على المصادر

1. لا يوجد في المصادر **فحص سريري تفصيلي** (اختبارات، مدى حركي، فحص عصبي). كل ذلك ➕ مضاف من البرومبت §6.
2. لا يوجد في المصادر حقل «القسم» أو «المعالج المسؤول»، وأضفناهما للصلاحيات.
3. بند «لا شيء مما سبق» في قسمي السلامة والأمراض لا يميز «لا» عن «لم يُسأل»، فاستُبدل بأسئلة مستقلة.
4. خلل ترميز في نص PDF لبعض الكلمات (مثل «أدوية الضع…»). اعتمدنا أقرب قراءة ووثقناها.
5. ملف [F] يحدد «حتى 22 جلسة» بينما البرومبت يمنع فرض 22 على الجميع. اعتمدنا: عدد الجلسات حقل في الخطة، والطباعة تدعم 22 سطراً.
6. ملف [F] فيه «الحركة تبدأ من هنا» و«دمشق - الميدان» وأرقام هاتف. تظهر رأسية التقرير بالاسم والشعار النصي فقط، وأرقام الهاتف قابلة للضبط من `.env`.
