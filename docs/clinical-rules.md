# القواعد السريرية وقواعد السلامة (V1 — أسفل الظهر)

> **تنبيه:** هذه القواعد كتبها المطوّر بصورة محافظة اعتماداً على الممارسة العامة. هي **ليست** بديلاً عن الحكم السريري، و**يجب** أن يراجعها مختص مخوّل في المركز ويعتمدها قبل الاستخدام الفعلي.
> - كود القواعد: `app/clinical/safety.py`، وإصدارها `RULES_VERSION`.
> - تعريف الأسئلة: `app/clinical/definitions.py`.
> - الاختبارات: `app/clinical/catalog_seed.py`.

## 1. مبادئ ثابتة

1. **الفراغ ليس «لا»:** كل سؤال يبدأ بحالة «لم يُسأل». القيم الممكنة: نعم/لا، أو الحالات «غير معروف» و«لم يُسأل» و«لا ينطبق» (الأخيرة حيث يُسمح بها فقط).
2. **إجابة المريض المسبقة لا تكفي:** أسئلة السلامة في الاستبيان المسبق (H4) تُعرض كمرجع فقط. السلامة تُقيَّم من أسئلة الحلقة `SF_*` التي يسألها المعالج صراحةً.
   - إن أجاب المريض «نعم» مسبقاً وسجّل المعالج «لا»، تلزم ملاحظة توضيحية، وإلا يبقى السؤال «غير محسوم».
3. **لا نموذج لغوي ولا ذكاء اصطناعي** في القرارات الحرجة. المحرك قواعد حتمية قابلة للاختبار، ويعرض «أي إجابات سببت التنبيه» و«ما الذي لم يُسأل بعد».
4. **علامة واحدة ليست تشخيصاً:** رسائل المراجعة تطلب الاستيضاح أو التقييم، ولا تسمّي تشخيصاً نهائياً.
5. **«لا توجد مؤشرات مبلّغ عنها»** تسمح بإكمال التقييم فقط. لا تعني آلياً أن كل جهاز أو إجراء آمن.

## 2. حالات فرز السلامة

| الحالة | متى | الأثر |
|---|---|---|
| `NOT_CONFIRMED` لم يتأكد بعد | لا توجد أي إجابة سلامة | تُمنع نتائج الاختبارات والإنهاء والخطة |
| `INCOMPLETE` غير مكتمل | سؤال إلزامي «غير معروف/لم يُسأل»، أو تعارض بلا ملاحظة | كالسابق، مع عرض سبب المنع لكل سؤال |
| `EMERGENCY` إسعافي | أي قاعدة من الفئة الإسعافية (حتى لو كانت أسئلة أخرى ناقصة) | تعليق الحلقة آلياً، وتعليق أي خطة مرسلة أو معتمدة، وحجب الاختبارات الاستفزازية والجلسات، وطلب توثيق قرار الإحالة. رفع التعليق لرئيس القسم أو المدير فقط، وبعد أن تتغير الإجابات بملاحظة المصدر |
| `NEEDS_REVIEW` يحتاج مراجعة | قاعدة عاجلة أو مراجعة | يُسمح بالتقييم. اعتماد الخطة يتطلب إقرار رئيس القسم أو المدير بكل تنبيه مفتوح بملاحظة مكتوبة |
| `NO_FLAGS_REPORTED` | كل الأسئلة الإلزامية «لا» صراحةً، بلا تعارض | استكمال التقييم |

## 3. القواعد

### إسعافية (EMERGENCY): إحالة فورية

| القاعدة | الإجابة المسببة |
|---|---|
| اشتباه ذيل الفرس | `SF_URINARY_RETENTION` أو `SF_BLADDER_BOWEL_CONTROL` أو `SF_SADDLE_NUMBNESS` = نعم |
| عجز عصبي سريع | `SF_PROGRESSIVE_WEAKNESS` أو `SF_SUDDEN_BALANCE_LOSS` = نعم، أو `LB_NEURO_CHANGE` = «تسوء بسرعة» |
| صدري/قلبي/وعائي حاد | `SF_CHEST_PAIN` أو `SF_DYSPNEA` أو `SF_ACUTE_VASCULAR` = نعم |

### عاجلة (URGENT): تقييم طبي قبل العلاج

| القاعدة | الإجابة المسببة |
|---|---|
| تورم/ألم ساق واحدة (سبب وعائي محتمل) | `SF_UNILATERAL_LEG_SWELLING` |
| إغماء أو دوار شديد | `SF_SYNCOPE` |
| حمى غير مفسرة | `SF_FEVER` |
| رضّ مع عامل هشاشة: هشاشة عظام، أو ستيرويدات، أو العمر ≥ 65، ولم يُستبعد الكسر طبياً | `COMBO:TRAUMA_FRAGILITY` |
| تاريخ سرطان مع: ألم ليلي، أو نقص وزن، أو توعك عام، أو (العمر ≥ 50 مع تفاقم) | `COMBO:MALIGNANCY` |
| حمى مع عامل خطر عدوى | `COMBO:INFECTION` |
| أعراض الساقين معاً مع تغير وظيفي جنسي حديث | `COMBO:CES_PARTIAL` |
| بعد الجراحة: عجز عصبي جديد، أو علامات جرح/حرارة | `LB:POSTOP_*` |

### مراجعة (REVIEW): استيضاح سريري

| الإجابة المسببة | ملاحظة |
|---|---|
| أعراض الساقين معاً | — |
| تغير وظيفي جنسي حديث | — |
| رضّ مهم | — |
| عامل خطر عدوى | — |
| تاريخ سرطان | يُؤخذ أيضاً من التاريخ الطبي `HX_COND_CANCER` |
| نقص وزن | — |
| ألم ليلي غير معتاد | — |
| توعك عام | — |

### علامات (Flags) تؤثر على مسارات أخرى

| العلامة | متى تُرفع | أثرها |
|---|---|---|
| `SUSPECTED_FRACTURE` | رضّ دون «استبعاد الكسر طبياً» | يحجب اختبارات المدى الحركي والاختبارات الاستفزازية |
| `PROVOCATIVE_TESTS_BLOCKED` | المسار إسعافي | يحجب SLR وSlump والحركات المتكررة |
| `SURGICAL_RESTRICTIONS_UNCLEAR` | جراحة دون تعليمات موثقة أو تأكيد بعدم وجود قيود | يحجب الاختبارات الاستفزازية، ويمنع إرسال الخطة واعتمادها |
| احتياطات الأجهزة: `ACTIVE_IMPLANT`, `METAL_IMPLANT`, `PREGNANCY_POSSIBLE`, `MALIGNANCY_HISTORY`, `REDUCED_SENSATION`, `ANTICOAGULANT`, `EPILEPSY`, `DIABETES` | من التاريخ الطبي أو الفحص | تُعرض على كل بند جهاز، ويلزم توثيق الاحتياطات. **لا يحكم النظام بأن جهازاً بعينه ممنوع**، فالمرجع تعليمات الشركة المصنعة |

> «حمل محتمل» يُرفع للأنثى حين تكون الإجابة نعم أو غير متأكدة، **أو حين لم يُسأل السؤال أصلاً** (لا افتراض للنفي).

## 4. التفرعات السريرية (show_if)

| الشرط | ما يظهر |
|---|---|
| امتداد للألية أو الفخذ أو أسفل الركبة أو القدم، أو تنميل أو وخز أو ضعف | مسار عصبي: توزع الأعراض، أيهما أشد، تغير الأعراض العصبية. ويوصى بفحص القطع العضلية والجلدية والمنعكسات وSLR/Slump |
| يزداد بالوقوف/المشي ويخف بالجلوس/الانثناء | مسار التفريق العصبي/الوعائي: ما يخفف الأعراض، الصعود والنزول، الدراجة، عوامل وعائية، النبض. ويوصى بالمشي الموقوت. **لا تشخيص آلي** |
| جراحة سابقة أو حديثة | النوع، التاريخ، تعليمات الجراح، القيود، علامات المضاعفات، إرفاق التقرير |
| رضّ أو سقوط | الآلية، التاريخ، هل استُبعد الكسر طبياً |
| صور طبية | نص التقرير منفصل عن الانطباع السريري، مع تنبيه بعدم تحديد مستوى الجذر من الرنين وحده |

الحركات المتكررة تُوثّق كما يلي، ولا تُفرض اتجاهاً علاجياً:
- الحركة المستخدمة وعدد التكرارات.
- الأعراض قبل وبعد.
- الاستجابة: تحسن، تفاقم، تمركز، انتشار محيطي، أو لا تغيير.

## 5. متطلبات إنهاء التقييم

1. سلامة مكتملة (لا «غير معروف» ولا «لم يُسأل» ولا تعارض بلا ملاحظة).
2. كل الأسئلة الإلزامية الظاهرة مجابة. الأسئلة المخفية بالتفرع لا تُطلب.
3. لكل اختبار «مستطب» نتيجة، أو «لم يُجرَ» مع السبب.
4. هدف قابل للقياس واحد على الأقل.
5. قياس بداية واحد على الأقل.
6. في المسار الإسعافي: قرار إحالة موثّق (من، متى، إلى أين).

أي تعديل بعد الإنهاء يعيد التقييم «قيد الإنجاز». الخطة المرسلة على إصدار تقييم قديم لا تُعتمد.

## 6. الخطة والاعتماد

**الحالات:** `DRAFT → SUBMITTED → (APPROVED | CHANGES_REQUESTED | ESCALATED | ON_HOLD)`.

| الحالة | الانتقالات المسموحة |
|---|---|
| `ESCALATED` | إلى `APPROVED` أو `CHANGES_REQUESTED` (المدير فقط)، أو `ON_HOLD` |
| `ON_HOLD` | `RESUME` إلى `SUBMITTED` |
| `APPROVED` | `SUPERSEDED` عند اعتماد إصدار أحدث، أو `ON_HOLD`، أو `CLOSED` عند إغلاق الحلقة |

**«إنشاء إصدار معدّل»** متاح من `CHANGES_REQUESTED` أو `ON_HOLD` أو `APPROVED`:
- ينشئ `DRAFT` جديداً.
- لا يمس الإصدار السابق ولا تعليقاته.
- يُعاد ضبط تأكيد مراجعة موانع الأجهزة في الإصدار الجديد.

**شروط الإرسال (على الخادم):**
- انطباع، ودرجة يقين، وعدد جلسات، وخطة إعادة تقييم.
- بند واحد على الأقل.
- جرعة لكل بند جهاز أو يدوي أو صالة أو منزل.
- معايير توقف لتمارين الصالة والمنزل.
- هدف لكل تقنية يدوية.
- تأكيد مراجعة الموانع لكل جهاز، واحتياطات مكتوبة إن وُجدت علامات احتياط.
- سلامة غير إسعافية ومكتملة.
- لا قيود جراحة غامضة.
- تقييم منتهٍ، وحلقة مفتوحة، وأهداف نشطة.

**شروط الاعتماد:** كل ما سبق، ومعه:
- المراجع ليس كاتب الإصدار. هذا مفروض في الكود **وفي قاعدة البيانات**: `CHECK approved_by <> author_id`.
- المراجع مخوّل للقسم. نائب الرئيس يحتاج تفويضاً نشطاً.
- المصعّدة يقررها المدير فقط.
- إصدار التقييم المرتبط هو الأحدث.
- لا تنبيهات مفتوحة دون إقرار مراجع.
- إقرار صريح بأن الأدلة رُوجعت يدوياً.

**التجميد:** محتوى أي إصدار غير `DRAFT` وبنوده مجمّدة بقيود في قاعدة البيانات.

## 7. الجلسات وإعادة التقييم

- لا جلسة دون إصدار `APPROVED`، ولا جلسة على حلقة معلّقة.
- الجلسة تُربط بإصدار الخطة لحظة إنشائها، ويمنع قيد في قاعدة البيانات تغيير هذا الربط لاحقاً.
- الإجراء خارج الخطة يتطلب مبرراً، ويرفع تنبيه «يحتاج مراجعة». الحدث غير المرغوب يرفع تنبيهاً مرتفع الخطورة.
- عند بلوغ الجلسة 6 أو 12 تظهر «مراجعة مستحقة». **لا تُمنع الجلسة السابعة** (قرار V1: تنبيه لا حجب، قابل للتغيير).
- مراجعة التطور تتطلب قياسات بنفس رموز البداية وأسمائها، وتحسب التغير بحسب اتجاه المقياس (الأقل أفضل للألم، والأعلى أفضل للوظيفة).
- يُطبع تنبيه بأن انخفاض الألم وحده ليس نجاح التأهيل.

## 8. المقاييس

**المستخدمة في V1:**
- الألم الرقمي 0–10.
- نشاط خاص بالمريض 0–10 على نمط PSFS.
- تحمّل المشي والجلوس.
- مسافة الأصابع-الأرض.
- النهوض من الجلوس 5 مرات.

**غير مفعّلة:** ODI وRMDQ موجودتان في الكتالوج **دون تفعيل**، لحين توفر نسخة عربية مرخصة وحق الاستخدام.

**مستبعد:** Waddell غير مضمّن، ولا يُستخدم لإثبات التمارض.
